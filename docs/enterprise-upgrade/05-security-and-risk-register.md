# Security and risk register

The review used ASVS 5.0.0 for authentication, authorization and validation, API Security for object-level access and resource limits, and the Cheat Sheets for cookies, CSRF and logging. UI checks target WCAG 2.2 AA. These are scoped checks of the paths listed in the verification report. [OWASP ASVS](https://asvs.owasp.org/) · [OWASP API Security](https://owasp.org/API-Security/) · [OWASP Cheat Sheets](https://cheatsheetseries.owasp.org/) · [WCAG 2.2](https://www.w3.org/TR/WCAG22/)

| Severity | Component | Evidence and root cause | Resolution or remaining action |
|---|---|---|---|
| High | REST read status and socket sends | Read path could mutate another thread. Socket implementation had separate privacy logic | Shared participant/recipient policy. HTTP denial, socket denial and sender spoofing tested |
| High | Direct share | Legacy Social handler tried demo aliases, then selected an arbitrary member when lookup failed | Share UI uses real contacts. Legacy route delegates to Messaging, where unresolved recipients and disallowed DMs fail |
| High | Message tombstones and previews | Delete-for-me could broadcast broadly. Shared deletion retained quote/attachment snapshots. Preview reads could disclose newly restricted content | Personal room delivery, shared scrub, policy-aware serialization and regression tests |
| High | Build contexts | Service Dockerfiles use `COPY . .`. No context ignore excluded `.env`, Windows dependencies or stored uploads | Context ignore files added. Compose syntax checked. Image rebuild and prior image/secret inventory remain release work |
| High | Session and preference validation | Arbitrary nested preference fields, global local storage, revocable sockets valid until disconnect | Allowlisted partial updates, scoped state, password-verified session revocation, bounded socket token lifetime and event validation |
| High | Import dependencies | Quiz audit reports `xlsx@0.18.5` without an npm audit fix, plus `body-parser` advisory. Other services also carry `xlsx` | Prioritize a vendor-supported parser upgrade and malicious-file tests. Keep the audited versions in this scoped pass |
| High | Desktop dependencies/runtime | `npm audit --omit=dev` reported 11 desktop findings, including four high. Node 20 used locally and by Dockerfiles has ended support | Run an explicit dependency remediation and supported LTS compatibility pass before public deployment |
| High | Multi-instance messaging | Process-local Socket.IO adapter, rate counters and last-seen map. No persisted replay | Single replica boundary. Block replica rollout until adapter/affinity/replay behavior is verified |
| High | Recovery and data policy | No verified backup restore, retention policy or private attachment lifecycle | Define recovery objectives, restore rehearsal, deletion policy and asset authorization before enterprise release |
| Medium | Gateway health and proxy headers | Always-healthy downstream handlers and client-supplied forwarded IPs. Unbounded waits | Dependency-aware 503, separate liveness, deadline and short health cache. Replace client-forwarded IP using configured trust and verify with a spoofing test |
| Medium | Chat load and abuse | Offset inbox, per-thread preview lookups, per-message unread rows, regex search | Bounded lists, query deadlines and per-account send/search budgets. Benchmark at production-like volume before changing read models |
| Medium | Auth | Single refresh token per user, all-device logout semantics, duplicated auth middleware | Password revocation and chat session checks verified. Dedicated session model, rotation/reuse detection and MFA remain deferred |
| Medium | Quiz and Challenge | Shared collections and legacy routes. Race behavior, full quarantine matrix and creator practice exclusions lack targeted concurrency evidence | Preserve competition behavior. Add race and authorization checks before changes to result or challenge ownership |
| Medium | Social, Admin and media | Several shared write/read projections, local image files, and unverified privilege/audit edge cases | Extend object-level policy coverage and scope service credentials. Move durable assets only after testing legacy access paths |

`npm ls` for the gateway and Messaging and installed package metadata for all ten services show `express@4.22.3 → proxy-addr@2.0.8`. The advisory affects versions below 2.0.8. No dependency override is needed for this advisory. Gateway proxy forwarding also replaces untrusted `X-Forwarded-For` when the default trust setting is in use. Set `TRUST_PROXY_HOPS` only to the actual number of trusted hops and keep downstream services private. [GHSA-jqcg-44mw-7w3h](https://github.com/advisories/GHSA-jqcg-44mw-7w3h)

Message text renders as React text. HTTP input limits are 32 KiB for the message service, with a 2,000-character text limit and ObjectId validation. Validated receipt data is distinct from internal read state. Logs in the changed request paths use request ID, operation, status, timing or error category. Other services still require a systematic logging audit. Platform-wide ASVS coverage, physical-device WCAG behavior, cross-origin production cookies, load targets and outage behavior are unverified.
