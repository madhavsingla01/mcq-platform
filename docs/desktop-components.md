# Desktop popups and filters

Use `SmallPopup` when an action needs a short decision or a compact form. Set an accessible title and add a description when the consequences need explanation. Keep the primary action at the end of the action row. For a destructive action, identify what will be deleted, place initial focus on Cancel and use the destructive styling for the confirmation. The dialog keeps keyboard focus inside while open and returns focus when dismissed. Escape dismisses an idle dialog. An action in progress keeps the dialog open until it finishes.

Keep popups centered, bounded by the viewport and scrollable when necessary. Use the app's shared surface, text and border colors. An anchored menu suits actions that only need a selection from a short list. Use a page or panel for a task that requires several sections or extended editing.

Use `FilterSelect` for a labelled filter with a short list of values. Keep page search in the shared header and apply it together with the page's filters. Explore uses the advanced search for the catalog.
